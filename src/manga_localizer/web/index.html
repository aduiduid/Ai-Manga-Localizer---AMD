设置

后端配置保存在本机；API 密钥仅保留在当前服务进程或环境变量中。

推荐使用策略：英／西文书用 llama.cpp（省显存、无后台进程、密集文本更稳），日文竖排书用 Ollama（不漏字、同页约快 3 倍）。两条路的坐标结果一致，可随时切换。

内置轻量翻译模型

使用 ModelScope 下载的 Hy-MT2 1.8B，适合低配置快速初译；质量模式推荐本机 Ollama。

质量模式只使用所选的 9B 或更小 Ollama 模型：先生成草稿，再与 Hy-MT2 独立候选做分阶段上下文审校，不下载更大的模型。

注：此模式使用专用 MT 模型单跑，速度极快且省显存，但在复杂语境下可能缺少 9B 的纠错能力，适合纯对话密集本。

llama.cpp 本地推理

直接加载 Ollama 已下载的 GGUF，不经过 Ollama 服务：主翻译与审校各起一个 llama-server 进程，占两个端口。模型名是 Ollama 清单标签，仅用于定位文件。

在线模式只发送 OCR 文本、前文和术语表，不上传漫画图片。

三步快速上手

  1. 先在“模型管理”准备所需权重。
  2. 选择源图片文件夹和独立输出目录。
  3. 点击“开始本地化”，任务可在记录页继续查看。

首次下载约需 5 GB；图片与结果不会上传。
